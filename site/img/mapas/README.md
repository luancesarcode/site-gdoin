# Mapa das cooperações

Base cartográfica: Natural Earth, países na escala 1:110 milhões, em domínio público.

- Dados: https://github.com/nvkelso/natural-earth-vector/blob/9380cca83db5f9aef52d5e762765100745f84b27/geojson/ne_110m_admin_0_countries.geojson
- Termos: https://www.naturalearthdata.com/about/terms-of-use/
- Projeção cilíndrica equidistante, com margem no SVG. Antártida omitida da visualização das cooperações.
- Os pontos representam países; as curvas são conexões ilustrativas a partir de Recife, não itinerários ou sedes exatas das instituições.
- Países vinculados às instituições já listadas na página: Brasil, Portugal, Itália, Canadá e China. O vínculo do ITN com Portugal foi conferido em https://joint-research-centre.ec.europa.eu/ehro-n/member-states-info/portugal_en.

O SVG é local. A página não depende de serviços de mapas, bibliotecas, fontes ou requisições a terceiros. O gerador está no repositório de trabalho, em `ferramentas/gerar_mapa_cooperacoes.py`.
